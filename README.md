# 轨道实验室 · 独立展示候选版

一个带轨道、粒子、巡游角色、仪表与程序合成音效的本地可视化。默认所有数值、事件、工作流和活动曲线均为虚构样例。

**版本 0.1.2，采用 MIT 许可，署名若若。完整条款见 `LICENSE`；开发来源和第三方边界见 `PROVENANCE.md`。本次仅私下交付，尚未上传公开网站或仓库。**

## 运行

优先打开 **`orbit-preview.html`**：这是单文件版，CSS、配置、模拟数据与代码全部内嵌，不用解压其他文件、开终端、安装软件或登录账号。下载附件后用已有浏览器打开即可；聊天应用内的附件预览不一定允许执行 HTML。

单文件与下述可编辑源码来自同一版本。单文件使用三个固定脚本哈希校验，禁止外部脚本及所有数据连接；样式保留内联许可以支持动画中的动态样式。修改源码后，开发者可运行 `node scripts/build-preview.cjs` 重新生成预览和哈希。不要手改内嵌脚本后删除 CSP 来“修复”运行。

源码版入口仍为 `index.html`，可与同目录资源一起用浏览器打开。运行页面不需要 Node.js、npm、账号、API key、数据库或后端服务。

五个运行文件是 `index.html`、`styles.css`、`config.js`、`data.js`、`app.js`。没有 CDN、外部字体、图片或音频下载。音效来自浏览器 Web Audio，默认关闭，点击「声音」启用。

## 使用与配置

- 顶部标签选择节点，右侧详情查看合成进程；点击日志或仪表右上角放大按钮打开详情。
- 「全景演示」播放约 24 秒的动画编排；「巡游」切换速度。它们不执行任务。
- 中心信标可展开活动曲线。演示中有独立的合成工作流进展与偶发检查告警。
- 页面读取系统的减少动态效果偏好；音频在标签页隐藏时停止。
- 修改 `config.js` 中的 `title`、`brand`、`central.name/color` 以及七个成员的 `name/model/color`。名称、模型只是展示文本，模型字段不会调用任何模型服务。
- 七个 `member1` 至 `member7` 是固定视觉槽位，数量、键和顺序保持不变。第 1 个关联巡游者，第 4 个关联检查交接，第 7 个作为中继；名称与颜色可以改变。材质纹理和部分装饰色仍属于固定视觉设计。
- `external: true` 可将某个槽位标成未启用；默认所有槽位启用。`tickMs` 为 500–10000 毫秒，默认 2000；`seed` 为 0–1000000 的整数，用于合成曲线相位，不代表整个动画完全可重复。
- 名称最长 24 字符、模型最长 32 字符、标题最长 40 字符、品牌最长 24 字符；颜色须为六位十六进制。配置无效时会显示提示并停止初始化。

配置文件作为可信本地 JavaScript 加载。运行数据走独立的校验接口，参见 `DATA_FORMAT.md`。

## 两种数据模式

默认显示 **SIMULATED**：每次刷新在内存中生成合成数据，断网不影响运行。

可选 **LOCAL INPUT**：你自己的本地代码可在页面加载完成后调用 `OrbitDemo.setSnapshot(snapshot)`。应用不主动请求任何数据地址，不携带认证，也不会加载所谓的“旧快照”。输入经过字段、类型、长度、枚举和数值范围校验；未知字段被丢弃。

本地输入在最后一次接收后 15 秒过期，下一次采样周期清除并恢复模拟；输入无效时立即清除并恢复模拟。可主动调用 `OrbitDemo.useDemo()`。日志、详情、动画标签、去重状态与工作流队列随数据模式清理。页面没有 localStorage、sessionStorage、IndexedDB 或 cookie 读写；不保存跨刷新数据。

页面 CSP 默认禁止网络连接、表单提交和对象嵌入。没有附带联网适配器；如果未来需要联网，应由使用者另外设计自己的认证、源限制、数据最小化与 CSP，不能把这里当作现成的远程监控客户端。

## 安全实现

数据驱动的日志、滚动信息、提示框、标题、标签和装饰代码使用 DOM 创建与 `textContent`。运行文件没有 `innerHTML` 等 HTML 字符串写入口。颜色限制为六位十六进制，快照使用显式字段投影；部件名称用 `Map` 索引，避免特殊对象键影响原型。

这里的校验和 CSP 不能替代未来联网产品的完整安全设计。本地数据仍会显示在当前页面；不要在用于截图或分享的演示会话中传入私人信息。

## 测试

运行基础检查不需要安装依赖：

```sh
node tests/unit.cjs
```

完整浏览器测试需要安装测试工具（仅开发依赖）：

```sh
npm install
npx playwright install chromium
npm run test:browser
```

也可以通过 `CHROME_EXECUTABLE` 指定已有 Chromium/Chrome 可执行文件。测试使用新建隔离会话、环回地址静态服务器和合成数据，不访问个人浏览器会话。截图与精简结果位于 `tests/`；安装的 `node_modules/` 不属于交付包。

测试覆盖启动、持续绘制、交互、音频开关、配置、无害 HTML 样例、特殊对象键、输入过期、无持久化、离线冷启动、移动视口、减少动态效果和网络资源白名单。浏览器测试记录见 `TEST_RESULTS.md`。音频验证到 AudioContext 和合成节点状态，未做听感评估。
